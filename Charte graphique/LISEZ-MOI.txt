CHOIX RETENUS PAR DÉFAUT (modifiables)

  Signature     « Une agilité sans limites. »
  Polices       Outfit et Figtree, celles du site yvris.net

POUR MODIFIER UNE COULEUR OU LA SIGNATURE
  1. Changer la valeur dans couleurs\tokens.json
  2. Lancer : python guide\build_guide.py   puis   python gabarits\build_gabarits.py
  Tout le guide et tous les gabarits sont régénérés avec la nouvelle valeur.

À SAVOIR
  - Le logo vectoriel a été retracé à partir du PNG officiel (721 px). Si le fichier source d'origine
    existe (AI, SVG, PDF), il doit remplacer les fichiers du dossier logo\.
  - Les valeurs CMJN sont une conversion approchée : demander une épreuve à l'imprimeur avant tirage.
  - Les noms, fonctions et mentions légales (RCCM, IFU) sont à compléter dans les gabarits.
  - Le modèle Word utilise Arial pour s'afficher correctement sur tous les postes.
