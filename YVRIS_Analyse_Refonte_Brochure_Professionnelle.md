# 1. Objectif du document

Ce document propose une refonte complète de la brochure YVRIS Business
Cloud afin de la rendre plus professionnelle, plus crédible, plus riche
visuellement et surtout plus efficace commercialement.

La maquette actuelle présente une bonne base graphique, mais elle
souffre d'un problème majeur : elle ressemble davantage à une
présentation minimaliste de site web qu'à une véritable brochure
commerciale.

L'objectif de la nouvelle version est de transformer la brochure en un
support qui :

-   explique immédiatement ce qu'est YVRIS ;
-   montre clairement les bénéfices pour l'entreprise ;
-   valorise les fonctionnalités sans surcharger ;
-   donne une impression de solution complète et mature ;
-   utilise davantage de visuels et de preuves ;
-   guide naturellement le lecteur vers une demande de démonstration ou
    une prise de contact.

------------------------------------------------------------------------

# 2. Analyse de YVRIS Business Cloud

## Positionnement identifié

YVRIS Business Cloud se positionne comme une solution ERP en ligne
destinée aux créateurs d'entreprise, TPE et PME.

La plateforme permet de centraliser plusieurs fonctions importantes de
l'entreprise autour d'un même environnement :

-   CRM ;
-   Ventes ;
-   Comptabilité ;
-   Ressources humaines ;
-   Gestion de stock ;
-   Production.

Le site met également en avant plusieurs arguments commerciaux
importants :

-   une instance dédiée ;
-   une solution hébergée et sauvegardée ;
-   des factures normalisées conformes aux exigences DGI ;
-   l'accompagnement par des experts-comptables ;
-   un abonnement prépayé sans engagement de durée ;
-   la possibilité d'activer les modules selon les besoins de
    l'entreprise.

## Message central à renforcer

La brochure ne doit pas seulement dire :

> « Nous avons plusieurs modules. »

Elle doit raconter :

> **« Votre entreprise est composée de plusieurs activités. YVRIS les
> rassemble dans un même environnement pour vous permettre de mieux
> gérer, suivre et piloter votre activité. »**

C'est ce changement de narration qui donnera une dimension plus premium
et commerciale à la brochure.

# 3. Diagnostic de la maquette actuelle

## Ce qui fonctionne

La proposition actuelle possède quelques bonnes bases :

-   identité visuelle moderne ;
-   univers corporate et technologique ;
-   palette sombre et professionnelle ;
-   bonne cohérence générale entre les pages ;
-   modules clairement identifiés.

## Ce qui pose problème

### 1. Trop de vide

Les grandes zones blanches ou sombres ne sont pas suffisamment
compensées par :

-   des visuels ;
-   des données ;
-   des captures de la plateforme ;
-   des arguments commerciaux ;
-   des éléments graphiques.

Le résultat donne une impression de brochure inachevée.

### 2. Les textes sont trop petits

Dans une brochure commerciale, les textes doivent rester lisibles
rapidement, y compris à l'impression.

Il faut :

-   augmenter la taille des descriptions ;
-   améliorer les contrastes ;
-   réduire les micro-textes décoratifs ;
-   privilégier des phrases courtes et fortes.

### 3. Manque de hiérarchie commerciale

Les pages montrent des fonctionnalités, mais elles ne construisent pas
suffisamment un argumentaire.

La brochure doit répondre progressivement à ces questions :

1.  Quel problème YVRIS résout-il ?
2.  Pour qui ?
3.  Pourquoi utiliser un ERP ?
4.  Quelles activités peut-on gérer ?
5.  Pourquoi choisir YVRIS ?
6.  Comment démarrer ?

### 4. Les modules sont sous-exploités

Les six modules sont actuellement présentés de manière très légère.

Or, chacun peut devenir un véritable argument commercial.

Il faut présenter les modules avec :

-   un bénéfice clair ;
-   quelques fonctionnalités clés ;
-   une icône ;
-   éventuellement une capture de l'interface.

### 5. Pas assez de preuve visuelle

Une brochure sur un logiciel doit montrer le logiciel.

Il est fortement recommandé d'intégrer :

-   captures d'écran réelles ;
-   mockups ordinateur portable ;
-   tablette ;
-   smartphone ;
-   tableaux de bord ;
-   graphiques ;
-   interfaces des modules.

Sans cela, le lecteur comprend l'idée, mais visualise difficilement le
produit.

### 6. Le contact final est trop pauvre

La dernière page actuelle laisse beaucoup d'espace inutilisé.

La page de contact doit devenir une véritable page de conversion avec :

-   un message fort ;
-   un appel à l'action ;
-   les coordonnées ;
-   le site ;
-   un QR Code ;
-   une invitation à demander une démonstration.

# 4. Direction stratégique recommandée

## Positionnement de communication

La brochure doit vendre YVRIS comme :

> **Le centre de pilotage de l'entreprise.**

Et non comme une simple liste de logiciels ou de modules.

## Ton éditorial

Le ton recommandé :

-   professionnel ;
-   clair ;
-   accessible ;
-   moderne ;
-   rassurant ;
-   orienté résultats.

Éviter :

-   les phrases trop techniques ;
-   les paragraphes longs ;
-   les descriptions génériques ;
-   les formulations trop institutionnelles.

Privilégier :

-   les bénéfices ;
-   les verbes d'action ;
-   les phrases courtes ;
-   les chiffres ou preuves lorsqu'ils sont disponibles et validés.

# 5. Nouvelle structure recommandée --- Brochure 8 pages

Une brochure de 8 pages permettra de raconter l'histoire correctement
sans tomber dans le catalogue trop chargé.

fichiers, le suivi devient plus complexe et la prise de décision plus

centralisées dans une plateforme unique, conçue pour évoluer avec les
besoins de votre entreprise.

## Visuel recommandé

### À gauche --- Avant

-   outils séparés ;
-   données dispersées.

### À droite --- Avec YVRIS

Un centre connecté :

**YVRIS BUSINESS CLOUD**

avec les six modules autour.

Utiliser une ligne ou un système de connexions pour matérialiser la
centralisation.

# 6. Recommandations de design

## Palette

Conserver l'identité existante :

-   bleu profond ;
-   blanc cassé ;
-   gris clair ;
-   accents bleus / violets.

Éviter d'ajouter trop de couleurs.

## Typographie

Utiliser deux niveaux forts :

### Titres

Une typographie moderne, géométrique et suffisamment grasse.

### Textes

Une sans-serif très lisible.

## Hiérarchie recommandée

### Niveau 1

Grande accroche de page.

### Niveau 2

Sous-titre explicatif.

### Niveau 3

Fonctionnalités ou bénéfices.

### Niveau 4

Micro-texte uniquement lorsque nécessaire.

## Règle importante

Si un texte est trop petit pour être lu confortablement dans un PDF ou
sur une impression, il n'apporte plus de valeur.

------------------------------------------------------------------------

# 7. Recommandations visuelles essentielles

## À ajouter absolument

### 1. Captures de la plateforme

C'est probablement l'amélioration la plus importante.

Une brochure logicielle doit montrer le produit.

Prévoir au minimum :

-   1 capture dashboard général ;
-   1 capture CRM ;
-   1 capture Ventes ;
-   1 capture Comptabilité ;
-   1 capture RH ;
-   1 capture Stock ;
-   1 capture Production.

Toutes les captures ne doivent pas forcément être affichées en grand.

Elles peuvent être utilisées :

-   dans des écrans d'ordinateur ;
-   dans des cartes ;
-   comme arrière-plans partiellement visibles ;
-   dans des mockups.

### 2. Mockups

Utiliser :

-   ordinateur portable ;
-   écran desktop ;
-   tablette ;
-   smartphone.

### 3. Photos humaines

Ne pas mettre des photos génériques partout.

Utiliser des images humaines uniquement pour renforcer :

-   la direction ;
-   la collaboration ;
-   la prise de décision ;
-   le travail d'équipe.

### 4. Data visualisation

Créer quelques graphiques décoratifs non présentés comme données
officielles :

-   évolution ;
-   flux ;
-   diagrammes ;
-   connexions ;
-   indicateurs.

# 8. Ce qu'il faut supprimer ou réduire

-   les grands espaces sans fonction ;
-   les micro-textes trop fins ;
-   les longues lignes descriptives ;
-   les éléments décoratifs trop faibles ;
-   les cartes avec trop peu de contenu ;
-   les titres génériques comme « Fonctionnalités clés » lorsqu'une
    accroche plus commerciale est possible.

------------------------------------------------------------------------

# 9. Système de composition recommandé

Chaque page doit respecter la formule suivante :

## 1 idée principale

Une seule idée forte par page.

## 1 grande accroche

Visible immédiatement.

## 1 élément visuel dominant

Photo, dashboard, mockup ou schéma.

## 3 à 6 informations secondaires

Pas davantage.

## 1 objectif commercial

Chaque page doit faire avancer le lecteur vers la compréhension et la
prise de contact.

# 13. Checklist avant validation

Avant de finaliser la brochure, vérifier :

-   [ ] Le lecteur comprend ce qu'est YVRIS dès la couverture.
-   [ ] Chaque page a une idée principale.
-   [ ] Les textes sont lisibles.
-   [ ] Les modules ont des bénéfices clairs.
-   [ ] La plateforme est réellement visible dans la brochure.
-   [ ] Les informations officielles correspondent au site et aux
    validations du client.
-   [ ] Les captures utilisées sont actuelles.
-   [ ] Le QR Code est fonctionnel.
-   [ ] Les coordonnées sont correctes.
-   [ ] La dernière page contient un appel à l'action clair.
-   [ ] Les espaces vides sont volontaires et servent la composition.
-   [ ] Aucun élément n'a été ajouté uniquement pour « remplir ».

# 14. Conclusion créative

La base actuelle possède une direction visuelle intéressante, mais elle
manque de substance.

La bonne évolution n'est pas simplement :

> « Ajouter plus de texte pour remplir les espaces. »

La bonne évolution est :

> **Créer une narration commerciale, ajouter des preuves visuelles,
> montrer le produit et construire une expérience de lecture
> cohérente.**

La future brochure doit donner cette impression :

# YVRIS n'est pas simplement une collection de modules.

# C'est un environnement conçu pour aider une entreprise à mieux organiser et piloter ses activités.
